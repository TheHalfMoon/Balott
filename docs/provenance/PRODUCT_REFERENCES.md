## Source-availability rule

Founder permission does not create source bytes for products whose implementation is not available to Balott. Product observation may inform requirements and competitive analysis, but direct code adoption requires an accessible, immutable source identity plus the provenance controls in `SOURCE_USE_AUTHORIZATION.md`.
